# Project Specifications & Calculation Formulas

เอกสารนี้ระบุรายละเอียดเกี่ยวกับสูตรการคำนวณและข้อกำหนด UI สำหรับแอปพลิเคชัน BMI Calculator (ช่วงน้ำหนักสุขภาพดีและน้ำหนักในอุดมคติ)

---

## 1. ข้อมูลนำเข้า (Input Data)

1. **ส่วนสูง (Height):** 
   - หน่วยหลัก: เซนติเมตร (cm)
   - ขอบเขตที่อนุญาต: 100 - 250 cm
2. **เพศ (Gender):**
   - ตัวเลือก: ชาย (Male) / หญิง (Female)
3. **หน่วยน้ำหนักสำหรับแสดงผล (Display Weight Unit):**
   - ตัวเลือก: กิโลกรัม (kg) / ปอนด์ (lbs)

---

## 2. สูตรการคำนวณ (Calculation Formulas)

### 2.1 การแปลงหน่วย (Unit Conversion)
- แปลงส่วนสูงจากเซนติเมตรเป็นเมตรเพื่อใช้ในสูตร BMI:
  $$\text{Height (m)} = \frac{\text{Height (cm)}}{100}$$
- แปลงน้ำหนักจากกิโลกรัมเป็นปอนด์เพื่อใช้แสดงผลตามหน่วยที่เลือก:
  $$\text{Weight (lbs)} = \text{Weight (kg)} \times 2.20462$$

---

### 2.2 ช่วงน้ำหนักที่เหมาะสมตามเกณฑ์ BMI (Healthy Weight Range)
คำนวณจากช่วงค่า BMI ที่ถือว่าดีต่อสุขภาพ (Normal Weight) โดยแยกเป็น 2 เกณฑ์:

#### **เกณฑ์สากล (WHO Criteria)**
ช่วง BMI ปกติคือ **18.5 – 24.9**
- น้ำหนักขั้นต่ำแนะนำ (Min Weight):
  $$\text{Min Weight (kg)} = 18.5 \times (\text{Height in meters})^2$$
- น้ำหนักสูงสุดแนะนำ (Max Weight):
  $$\text{Max Weight (kg)} = 24.9 \times (\text{Height in meters})^2$$

#### **เกณฑ์เอเชีย (Asian Criteria)**
ช่วง BMI ปกติคือ **18.5 – 22.9**
- น้ำหนักขั้นต่ำแนะนำ (Min Weight):
  $$\text{Min Weight (kg)} = 18.5 \times (\text{Height in meters})^2$$
- น้ำหนักสูงสุดแนะนำ (Max Weight):
  $$\text{Max Weight (kg)} = 22.9 \times (\text{Height in meters})^2$$

---

### 2.3 น้ำหนักในอุดมคติ (Ideal Body Weight - IBW)
ใช้สูตร **Devine Formula (1974)** ซึ่งเป็นสูตรมาตรฐานทางการแพทย์:

- **แปลงส่วนสูงเป็นนิ้ว (Inches):**
  $$\text{Height (in)} = \frac{\text{Height (cm)}}{2.54}$$
- **สูตรคำนวณ:**
  - **เพศชาย (Male):**
    $$\text{IBW (kg)} = 50.0 + 2.3 \times (\text{Height (in)} - 60)$$
  - **เพศหญิง (Female):**
    $$\text{IBW (kg)} = 45.5 + 2.3 \times (\text{Height (in)} - 60)$$

#### **กรณีพิเศษ (Edge Case: ส่วนสูงต่ำกว่า 5 ฟุต / 152.4 cm):**
หากส่วนสูงน้อยกว่า 60 นิ้ว (152.4 cm) ให้ใช้การลบออกตามสัดส่วน หรือคงค่าเริ่มต้นขั้นต่ำไว้ที่:
- เพศชาย: 50.0 kg
- เพศหญิง: 45.5 kg
*(เพื่อป้องกันไม่ให้ค่าผลลัพธ์ติดลบหรือน้อยเกินไป)*

### 2.4 การแบ่งช่วงสถานะน้ำหนักตามดัชนีมวลกาย (BMI Category Ranges)
เราจะแสดงสถานะช่วงน้ำหนักตามค่าดัชนีมวลกาย (BMI) โดยอิงตามเกณฑ์เอเชียดังนี้เพื่อให้ผู้ใช้เห็นสถานะของตัวเองชัดเจน:
- **น้อยกว่า 18.5:** น้ำหนักต่ำกว่าเกณฑ์
- **18.5 – 22.9:** น้ำหนักปกติ (เหมาะสมที่สุด)
- **23.0 – 24.9:** น้ำหนักเกิน
- **25.0 ขึ้นไป:** ภาวะโรคอ้วน

### 2.5 คำแนะนำรอบเอวที่เหมาะสม (Recommended Target Waist Circumference)
ระบบจะทำการแสดงคำแนะนำรอบเอวที่เหมาะสมเพื่อสุขภาวะที่ดี (ป้องกันภาวะอ้วนลงพุง) โดยคำนวณจากส่วนสูงและเพศแบบเรียลไทม์โดยใช้เกณฑ์ WHtR และเกณฑ์เอเชีย:
- **เพศชาย (Male):** รอบเอวไม่ควรเกิน $\min\left(\frac{\text{Height (cm)}}{2}, 90\right)$ ซม.
- **เพศหญิง (Female):** รอบเอวไม่ควรเกิน $\min\left(\frac{\text{Height (cm)}}{2}, 80\right)$ ซม.

*หมายเหตุ: ในการแสดงผลบนหน้าจอ จะแปลงเป็นหน่วยนิ้วเพื่อความคุ้นชินของผู้ใช้ร่วมด้วย ($\text{Waist (in)} = \frac{\text{Waist (cm)}}{2.54}$)*

## 6. การตรวจสอบความถูกต้องของข้อมูลนำเข้า (Input Validation & Safety Bounds)

เพื่อให้โปรแกรมทำงานได้อย่างถูกต้อง เสถียร และปลอดภัยจากการป้อนข้อมูลที่ผิดพลาด (Input Error) เราต้องปฏิบัติตามกฎดังต่อไปนี้:

### 6.1 ขอบเขตของส่วนสูงที่อนุญาต (Height Safety Bounds)
- **ค่าต่ำสุด (Min Height):** 100 cm
- **ค่าสูงสุด (Max Height):** 250 cm

### 6.2 การตรวจสอบข้อมูลที่ป้อน (Input Validation Rules)
1. **ชนิดข้อมูล (Data Type):** ต้องรับเฉพาะจำนวนเต็มบวก (Positive Integer) เท่านั้น ห้ามกรอกตัวอักษร อักขระพิเศษ หรือจุดทศนิยม
2. **ขีดจำกัดค่าว่าง (Empty Input Handling):** หากผู้ใช้ลบตัวเลขจนกล่องข้อความเป็นค่าว่าง:
   - ระบบต้องไม่ทำการคำนวณใหม่โดยใช้ค่าว่าง (เพื่อป้องกัน `NaN` หรือโปรแกรมแครช)
   - ระบบจะแสดงข้อความแจ้งเตือนสีแดงเตือนให้ป้อนข้อมูล
3. **การพิมพ์ค่านอกขอบเขต (Out-of-Bounds Input):** 
   - หากผู้ใช้พิมพ์ตัวเลขที่น้อยกว่า 100 หรือมากกว่า 250 ตัวกล่องข้อความจะแสดงสถานะ Error (ขอบสีแดง) และแสดงคำเตือนใต้ช่องป้อน
   - ระบบจะแสดงผลการคำนวณค้างไว้ที่ค่าที่ถูกต้องล่าสุด (Last Valid Value) เพื่อความปลอดภัยและไม่ให้ผลลัพธ์การคำนวณพัง
4. **ความสอดคล้องของการควบคุม (Control Synchronization):**
   - เมื่อขยับ Slider $\rightarrow$ ค่าในกล่องป้อนตัวเลขต้องอัปเดตตามแบบเรียลไทม์
   - เมื่อพิมพ์ตัวเลขในกล่องข้อความ (และค่าถูกต้อง) $\rightarrow$ ตัวเลื่อน Slider ต้องขยับไปยังตำแหน่งนั้นโดยอัตโนมัติ

## 7. ข้อพิจารณาพิเศษในการออกแบบ Layout และระบบการเรนเดอร์ (Layout & Rendering Considerations)

เพื่อป้องกันการเกิดข้อผิดพลาดในการแสดงผลข้ามแพลตฟอร์ม (Cross-Platform UI issues) ต้องปฏิบัติตามข้อกำหนดทางเทคนิคต่อไปนี้:

### 7.1 การป้องกันข้อความหน่วยวัดหดตัว (Unit Squeezing Prevention)
- **ปัญหา:** หน่วยวัดความสูง (`cm`) ที่วางถัดจากช่องป้อนค่าแบบกรอกตัวเลข อาจโดนแรงบีบจาก Flexbox บนจอขนาดเล็ก (Mobile Viewport) จนความกว้างของข้อความหดตัว ทำให้ตัวอักษร `m` เสียรูปหรือถูกขลิบขวาจนดูเสมือนเป็นตัว `n` (`cn`)
- **การปฏิบัติตาม:** ในโค้ดหน้าจอ (รวมถึง Flutter UI) สัญลักษณ์หน่วยวัดจะต้องถูกล็อกค่าไม่ให้หดตัว เช่น การใช้คำสั่ง `flex-shrink: 0` หรือการระบุขนาดความกว้างขั้นต่ำของตัวอักษร (`min-width` หรือการใช้กล่อง `SizedBox` กำหนดขนาดแน่นอน)

### 7.2 ระยะห่างแนวตั้งเพื่อความสมบูรณ์ของวรรณยุกต์ไทย (Thai Font Vertical Headroom)
- **ปัญหา:** ตัวหนังสือภาษาไทยที่มีการไล่สี (Gradient Text) หรือถูกจำกัดกรอบความกว้างในระดับบรรทัดที่กระชับเกินไป อาจเกิดปัญหาวรรณยุกต์หรือสระแถวบนสุด (เช่น ่, ้, ๊, ๋, ิ, ี, ึ, ื) โดนขลิบตัดส่วนบนสุดทิ้งไปโดยระบบการเรนเดอร์ของบราวเซอร์
- **การปฏิบัติตาม:** สำหรับหัวข้อและคำอธิบายภาษาไทยในทุกๆ จุด ต้องกำหนดอัตราส่วนความสูงบรรทัด (เช่น `line-height: 1.4` ใน CSS หรือ `TextStyle(height: 1.3)` ใน Flutter) พร้อมเผื่อพื้นที่ระยะห่างขอบบนและล่าง (Vertical Padding) เพื่อให้เครื่องมือวาดข้อความมีระยะวาดส่วนหัวของวรรณยุกต์ไทยได้อย่างถูกต้อง

### 7.3 การใช้เลย์เอาต์พับบรรทัดอัตโนมัติสำหรับกล่องคำอธิบาย (Responsive Wrap for Legend Labels)
- **ปัญหา:** แถบสีอธิบายช่วงระดับน้ำหนัก (Legend) ที่อยู่ด้านล่างสุด หากกำหนดให้เรียงเป็นแถวเดียวแนวนอน (`Row`) จะเกิดปัญหาข้อความภาษาอังกฤษซึ่งยาวกว่าภาษาไทยเบียดเสียดกันจนทับซ้อนกับจุดสีบอกสถานะข้างเคียง
- **การปฏิบัติตาม:** บนการแสดงผลหน้าจอมือถือหรือขนาดเล็ก (Mobile Screen) ให้เปลี่ยนเลย์เอาต์จาก `Row` ไปเป็นกล่องที่พับบรรทัดได้โดยอัตโนมัติ (เช่น CSS `flex-wrap: wrap` หรือใช้วิดเจ็ต `Wrap` ของ Flutter แทน `Row`) และกำหนดระยะห่างระหว่างรายการ (`gap`) ทั้งแนวตั้งและแนวนอนให้เหมาะสม
