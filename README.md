# Ideal Weight Finder (เครื่องมือคำนวณน้ำหนักที่เหมาะสม)

แอปพลิเคชันเครื่องมือคำนวณน้ำหนักที่เหมาะสมและวิเคราะห์ผลลัพธ์เพื่อสุขภาวะที่ดี รองรับการใช้งานข้ามแพลตฟอร์ม (Cross-Platform) อย่างเต็มรูปแบบ พัฒนาขึ้นโดยใช้เฟรมเวิร์ก **Flutter (Dart)** ภายใต้สถาปัตยกรรม **MVVM (Model-View-ViewModel)**

---

## ฟีเจอร์หลัก (Core Features)

1.  **คำนวณน้ำหนักตัวในอุดมคติ (Ideal Body Weight):** คำนวณแบบเรียลไทม์ผ่านสูตรทางการแพทย์ **Devine Formula (1974)** พร้อมระบบความปลอดภัยสำหรับผู้ใช้งานที่ส่วนสูงต่ำกว่า 5 ฟุต (152.4 ซม.) โดยควบคุมน้ำหนักฐานขั้นต่ำไว้อย่างถูกต้อง
2.  **คำแนะนำรอบเอวสูงสุดเพื่อสุขภาพ (Target Waist Circumference):** ประเมินและแนะนำขนาดรอบเอวสูงสุดเพื่อลดความเสี่ยงภาวะอ้วนลงพุง โดยใช้เกณฑ์ Waist-to-Height Ratio (WHtR < 0.5) และเกณฑ์จำกัดภูมิภาคเอเชีย (ชายไม่เกิน 90 ซม. / หญิงไม่เกิน 80 ซม.)
3.  **วิเคราะห์ระดับน้ำหนักตามเกณฑ์ดัชนีมวลกาย (WHO & Asian BMI Ranges):** แสดงแถบเปรียบเทียบสัดส่วนน้ำหนักสุขภาพดีแบบ 4 ระดับ (Underweight -> Normal -> Overweight -> Obese) โดยเปรียบเทียบให้เห็นชัดเจนทั้งเกณฑ์สากล (WHO) และเกณฑ์เอเชีย
4.  **สลับหน่วยวัดแบบเรียลไทม์ (Real-time Unit Switching):** รองรับการกดสลับหน่วยแสดงผลน้ำหนักระหว่าง **กิโลกรัม (kg)** และ **ปอนด์ (lbs)** รวมถึงสัญลักษณ์รอบเอวเป็นนิ้ว (inches) โดยแปลงค่าทันที
5.  **ระบบ 2 ภาษาในตัว (Dual-Language Support):** สลับภาษาใช้งานได้ระหว่าง **ภาษาไทย (TH)** และ **ภาษาอังกฤษ (EN)** ทันทีโดยไม่ต้องตั้งค่าอุปกรณ์
6.  **ระบบ 2 ธีมสีสไตล์พรีเมียม (Theme Switching):** รองรับการสลับธีมระหว่าง **โหมดมืด (Dark Mode)** ดีไซน์แก้วกึ่งโปร่งแสง Glassmorphism และ **โหมดสว่าง (Light Mode)** สีทึบความเปรียบต่างสูง (High Contrast) เพื่อความสบายตาและอ่านง่าย

## สถาปัตยกรรมของโปรเจกต์ (Project Structure)

โปรเจกต์นี้เขียนขึ้นตามแนวคิดการแยกส่วนทำงานออกจากกันอย่างชัดเจน (Separation of Concerns) ตามรูปแบบ MVVM:

```text
lib/
├── core/               # การตั้งค่าหลักของแอปพลิเคชัน
│   ├── theme.dart      # โทนสี ธีมมืด/สว่าง ฟอนต์ และการรักษาวรรณยุกต์ไทย
│   └── localization.dart # พจนานุกรมแปลภาษาไทย/อังกฤษ แบบ Offline-first
├── models/             # ส่วนของข้อมูลและสูตรคำนวณทางคณิตศาสตร์ (Business Logic)
│   ├── calculator_result.dart # โครงสร้างผลลัพธ์สุขภาพ
│   └── calculator_model.dart  # สูตร Devine, ขีดจำกัดรอบเอว และช่วง BMI
├── viewmodels/         # ส่วนเชื่อมประสานการทำงานและตรวจสอบข้อมูล (UI State)
│   └── calculator_viewmodel.dart # จัดการ State ซิงก์ Slider และจัดเก็บค่าแบบออฟไลน์
└── views/              # ส่วนการแสดงผลติดต่อผู้ใช้งาน (UI Presentation Layer)
    ├── home_page.dart  # หน้าหลักรองรับ Responsive Layout (Desktop/Mobile)
    └── widgets/        # วิดเจ็ตประกอบย่อยส่วนต่างๆ
        ├── gender_selector.dart # ปุ่มเลือกเพศพร้อมอนิเมชัน
        ├── height_slider.dart   # สไลเดอร์ความสูงพร้อมช่องกรอกและแถบเตือนสีแดง
        ├── result_card.dart     # การ์ดแสดงผลลัพธ์กรอบสีเด่น
        └── segmented_range_bar.dart # แถบสัดส่วนสีรายงานขีดจำกัดน้ำหนัก
```

## ขั้นตอนการติดตั้งและเริ่มใช้งาน (Getting Started)

### ความต้องการของระบบ (Prerequisites)
- **Flutter SDK:** เวอร์ชัน `3.22.0` หรือสูงกว่า (รุ่นเสถียร - Stable)
- **Dart SDK:** เวอร์ชัน `3.12.1` หรือสูงกว่า (ตามข้อกำหนดของสภาพแวดล้อม)
- **Developer Mode (โหมดนักพัฒนา):** ทำการเปิดใช้งานบนระบบปฏิบัติการ Windows ของคุณก่อนรันคำสั่ง (ต้องการสำหรับการสร้าง symlink ของโฟลเดอร์สำหรับ `shared_preferences`)

### 1. ดาวน์โหลด Dependencies
เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วรันคำสั่ง:
```bash
flutter pub get
```

### 2. รันแอปพลิเคชันในโหมดพัฒนา (Development Mode)
ในโหมดพัฒนาจะรองรับการทำ **Hot Reload** ช่วยให้ประหยัดเวลาเมื่อแก้ไขโค้ด:

-   **เปิดใช้งานบน Web (Chrome):**
    ```bash
    flutter run -d chrome
    ```
-   **เปิดใช้งานเป็นแอปพลิเคชัน Windows Desktop:**
    ```bash
    flutter run -d windows
    ```

### 3. รันชุดทดสอบยูนิตเทส (Running Unit Tests)
เพื่อตรวจสอบความถูกต้องของระบบประมวลผลคำนวณคณิตศาสตร์และ State ของ ViewModel:
```bash
flutter test
```

### 4. คอมไพล์และเปิดใช้งานเวอร์ชันใช้งานจริง (Production Build - Web)
ทำการคอมไพล์โค้ดเป็น HTML/JS สำเร็จรูปสำหรับขึ้นเซิร์ฟเวอร์จริง:
```bash
flutter build web
```

เมื่อคอมไพล์เสร็จสิ้น ผลลัพธ์จะไปอยู่ที่โฟลเดอร์ `build/web/` คุณสามารถจำลองเปิดหน้าเว็บในเครื่องโลคอลได้โดยเปิดเซิร์ฟเวอร์แบบเบาด้วยเครื่องมือต่อไปนี้:

-   **รันผ่าน Node.js (npx):**
    ```bash
    npx http-server build/web -p 8000
    ```
-   **รันผ่าน Python:**
    ```bash
    python -m http.server 8000 --directory build/web
    ```
จากนั้นให้เปิดบราวเซอร์และพิมพ์เข้าใช้งานที่ลิงก์: **`http://localhost:8000`**
